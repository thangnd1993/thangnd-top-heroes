# Top Heroes Auto Manager

Ứng dụng desktop **Windows**, Python 3.12 + PySide6, quản lý LDPlayer theo nguyên tắc
**một instance = một tài khoản**. Phát triển bởi Thang Nguyen.

Đang triển khai Phase 1. Không đăng nhập game, không lưu mật khẩu, không chạy gameplay macro.
Chỉ instance được chọn và không được bảo vệ mới có thể nhận thao tác.

Xem [tiến độ](docs/PROGRESS.md) và [thiết kế an toàn](docs/SAFETY.md).
