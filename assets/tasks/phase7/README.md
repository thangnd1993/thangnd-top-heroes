# Guild and Mail visual anchors

User-provided game references: Desktop/demo/phase7_*.png (2026-09-27).
Only clean game UI cores are runtime anchors; annotation strokes, names, mail
contents, timers, contribution totals and reward counts are excluded. Source
rectangles in manifest.json are extraction provenance, never runtime tap points.

All targets are searched in each current screenshot. Page pairs, uniqueness,
undimmed appearance, color/geometry and local badge association are independent
requirements. Unknown or conflicting evidence never authorizes input.

The two single-digit badge templates include the full badge, so an OCR failure
cannot read a lone digit from within a larger number. Other unread numbers stay
UNKNOWN. Windows OCR runs locally without uploading screenshots.

The ten annotated regression references are NOT clean real acceptance frames.
The member-gift count in particular intersects a blue annotation and can remain
UNKNOWN; never relax the threshold to recover that obscured number.
